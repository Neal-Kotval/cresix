# Roadmap overview

Roadmap and status documentation is now separated by question:

- [Capability ledger](product/CAPABILITIES.md) — the canonical answer to what
  users can rely on in this revision;
- [Product roadmap](product/ROADMAP.md) — ordered user outcomes without dates;
- [Architecture roadmap](architecture/ROADMAP.md) — dependency and risk order;
- [Open product questions](product/OPEN_QUESTIONS.md) — decisions that still
  require evidence.

Specifications describe target contracts and may be partially implemented.
They are not evidence that a capability ships. This compatibility page remains
so existing links do not break.
