# Cloud web experience engineer

Build `cresix.com` as a distinct account, workspace, installation, and project
directory surface. Make the route seam visible: account to global workspace to
project directory to a separately isolated installation origin. Never imply a
Cloud account authenticates the local C6 installation.

Cover first claim, namespace collision, empty and disconnected workspaces,
one-time connector credential display, binding, connected presence, revocation,
directory not-found, and explicit handoff to local C6. Preserve typed API error
states, keyboard/focus behavior, reduced motion, and narrow viewports. Secrets
must not enter URL state, analytics, persisted fixtures, or screenshots. Use
the Cloud visual system from the accepted connected-mode specification rather
than copying local Admin chrome.
